# 07：格式栏与编辑/预览切换

**要做什么：** 编辑器获得焦点时顶部出现格式栏，禅模式下一直显示，提供标题、粗体、斜体、删除线、引用、无序列表、有序列表、任务、行内代码、代码块、链接、公式等按钮，以及「编辑 | 预览」切换。预览使用与时间线完全相同的渲染器，看到的就是保存后的效果。
