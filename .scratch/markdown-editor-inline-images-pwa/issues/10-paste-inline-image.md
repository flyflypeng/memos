# 10：粘贴截图成为内嵌图片（主干切片）

**要做什么：** 在编辑器中粘贴截图，图片会出现在光标处，作为内嵌图片属于所在 Memo，保存后在正文中原位显示，不会在附件列表中重复出现。这一张工单打通「粘贴 → 上传 → 正文引用 → 保存关联 → 阅读视图」的完整链路。

**被阻塞于：** 02、06

**Status:** resolved

- [ ] 剪贴板含有非空文本时粘贴文本；只有图片文件时作为内嵌图片上传；其他文件作为附件
- [ ] 上传期间在插入位置显示占位符，期间继续输入不会错位；成功后替换为 `![](/file/resources/{id}/pasted-YYYYMMDD-HHmmss.<ext>)`；失败则移除占位符并提示
- [ ] 一次粘贴多张图片时按顺序插入
- [ ] 保存时由资源处理纯函数（S3）计算要关联的资源：正文引用的、本次上传的、无主的资源关联到该 Memo
- [ ] 阅读视图和编辑器的附件列表都隐藏被正文引用的资源；相对路径、当前域名绝对 URL、`![[resources/uid]]` 三种引用都识别（也适用于旧 Memo）
- [ ] 私有 Memo 的内嵌图片未登录时无法访问（人工验证）
- [ ] S2 测试覆盖粘贴判断和占位符替换，S3 测试覆盖基础关联规则
