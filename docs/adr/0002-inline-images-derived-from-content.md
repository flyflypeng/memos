# 内嵌图片与附件的区分由 Memo 正文推导，不单独存储

粘贴或拖放的图片会在光标处插入 Memo 正文，格式为 `![](/file/resources/{id}/{filename})`。一个资源是内嵌图片还是附件，不单独存储：

- 属于该 Memo、且在其 Memo 正文中被引用的资源是内嵌图片，不在附件列表中显示。以下三种写法都算引用：相对路径 `/file/resources/{id}/…`、当前域名下的绝对 URL、`![[resources/uid]]`。
- 该 Memo 的其他资源都是附件。

内嵌图片仍然属于所在 Memo，因此可见性与 Memo 相同，并随 Memo 一起删除。

我们没有选择把粘贴的图片留作不关联 Memo 的 URL。原因是：不属于任何 Memo 的资源，任何人只要知道 URL 就能读取（资源 id 是自增的），而且永远不会被清理。

## 后果

- 从 Memo 正文中删除图片引用并保存，会删除该资源及其文件，前提是这个资源在打开编辑器时已被引用，或者是在本次编辑中插入的。打开编辑器时就是附件的资源，仍然保持为附件。
- 引用另一条 Memo 的资源只算引用：资源仍归原 Memo，可见性跟随原 Memo，原 Memo 删除后引用会失效。
- 编辑已有 Memo 时点击取消，会删除本次编辑中上传的资源。尚未保存的新 Memo 草稿中的图片，在草稿保存前一直是未使用资源，或者由用户手动清理。
- 不需要数据库迁移。
